# Screenshots

Screenshots are intentionally not included in this first package.

Recommended images before a GitHub release:

- `overview-en.png` / `overview-uk.png`
- `profiles-en.png` / `profiles-uk.png`
- `eeprom-en.png` / `eeprom-uk.png`
- `settings-en.png` / `settings-uk.png`

Use the corresponding dashboard version, read EEPROM after reboot, and avoid exposing private addresses, credentials, Wi-Fi names, system identifiers or unrelated Home Assistant data. Do not crop away failures or disclaim tests not completed.
