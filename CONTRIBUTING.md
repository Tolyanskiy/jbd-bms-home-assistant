# Contributing

Thanks for helping improve the JBD BMS Configurator.

1. Reproduce and describe the issue, including JBD exact model, PCB revision, ESPHome version, controller model, and non-sensitive logs.
2. Before reporting a dashboard problem, check entity IDs in Developer Tools → States. Do not paste device secrets, Wi-Fi credentials, public IPs or personally identifiable data.
3. Keep all firmware/code comments in **English**. Preserve separate **English** and **Ukrainian** dashboards.
4. Preserve UART commands and the EEPROM APPLY transaction unless a change is supported by protocol evidence and tested in a controlled hardware environment.
5. Include validation results and clearly distinguish static review from successful hardware testing.
6. Do not add external source files without checking their copyright and license requirements.
