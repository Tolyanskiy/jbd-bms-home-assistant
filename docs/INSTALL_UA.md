# Встановлення (Українська)

1. **Перевір обладнання:** конфігурацію підготовлено для ESP32-C3 Zero та 4S JBD DP04S007-L4S; звір розпіновку й рівні сигналів UART.
2. **Секрети:** скопіюй `secrets.yaml.example` до свого локального каталогу ESPHome під назвою `secrets.yaml`; введи Wi-Fi та API ключ. Або використай наявні записи ESPHome. У GitHub реальні секрети не додавай.
3. **Вибери прошивку:** `firmware/jbd-bms-ua.yaml` або `firmware/jbd-bms-en.yaml`. Алгоритми та ID сутностей однакові, відмінність — мова статусів профілів.
4. **Звір конфігурацію:** назва пристрою `jbd-bms`, GPIO4 TX, GPIO5 RX, UART 9600, секрет API шифрування.
5. **Перевір і встанови:** ESPHome → Validate → Install. Повну компіляцію необхідно перевірити на твоєму ESPHome.
6. **Перевір моніторинг:** чотири групи, загальна напруга, струм, BMS Online.
7. **Додай Dashboard:** Home Assistant → редагування окремої панелі → редактор сирої конфігурації → повністю встав YAML `dashboards/jbd-dashboard-uk.yaml` (або `-en.yaml`).
8. **Перевір `entity_id`:** якщо в HA інші суфікси/імена сутностей, їх треба узгодити з Dashboard. Діагностичні сутності можуть бути вимкнені за замовчуванням.
9. **EEPROM:** натисни «Зчитати всі 10 параметрів», дочекайся `Read 10/10; exit confirmed; NO WRITE`. Після перезапуску ESP32 читай повторно перед порівнянням.
10. **Профілі:** редагування → «Зберегти мій профіль» → розблокувати DRAFT → завантажити → перевірити. Операції з профілями **не записують EEPROM**. APPLY — окрема операція на вкладці «Налаштування».

## Мови

При простій заміні панелі на англомовну написи й підказки стануть англійськими, але деякі статуси профілів можуть залишитися українськими, якщо ESP32 працює на UA-прошивці. Для повністю англомовних скриншотів передбачено EN-прошивку.

## Якщо виникли проблеми

- `unknown` — EEPROM ще не читали після поточного запуску ESP32.
- Немає сутностей — звір IDs у Developer Tools → States, назву ESPHome пристрою та діагностичні сутності.
- Немає UART телеметрії — перевір TX/RX, спільний опорний GND, логічні рівні, швидкість та стан зовнішнього компонента.


## Параметри UART публічної версії

Прошивка вже налаштована на `logger.level: WARN`, `update_interval: 5s` і `rx_timeout: 300ms`. Спостереження автора: після цих змін зв’язок працював без попередніх помилок.
