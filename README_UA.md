# JBD BMS ESPHome Configurator

**Моніторинг, читання й налаштування EEPROM JBD BMS через ESPHome та Home Assistant.** Є англійська й українська версії Dashboard.

> **Статус: v0.1.0-beta.** Власник проєкту перевірив роботу з **JBD DP04S007-L4S 60A (4S, V2.1)** і **ESP32-C3 Zero**, зокрема запис APPLY та читання параметрів назад. Для опублікованого пакета виконано статичний аудит; незалежних тестів усіх захистів та локальної компіляції ESPHome в цьому середовищі не проводили.

## Можливості

- Телеметрія комірок і батареї, струм, потужність, SOC, температури, активні захисти та лічильники.
- Керування розрядним MOSFET і відображення його стану.
- Незалежне читання **10 параметрів EEPROM** без запису та порівняння з DRAFT.
- Підготовка порогів, валідація, захищений APPLY із резервним читанням та повторною перевіркою.
- Проєктний та користувацький профілі; завантаження профілю змінює **тільки DRAFT**.
- Дві повні версії панелі Home Assistant по шість вкладок: **українська й англійська**.

## Швидкий початок

1. Перевір сумісність своєї BMS, електричні рівні UART та джерело живлення ESP32.
2. Скопіюй потрібний ESPHome YAML. Для Wi-Fi та API використовуються ключі з локального `secrets.yaml` (приклад у `secrets.yaml.example`). **Реальні секрети не публікуй.**
3. Встанови через ESPHome Device Builder: **Validate → Install**.
4. У Home Assistant створи або відкрий Dashboard → **Edit → Raw configuration editor** та встав YAML потрібної мови.
5. Перевір телеметрію, виконай **«Зчитати всі 10 параметрів»** на вкладці EEPROM.
6. Для перемикання мови інтерфейсу достатньо замінити YAML Dashboard. Якщо потрібні англійські також і динамічні статуси профілів, використовуй EN-прошивку.

Робочий UART у прикладі: **ESP TX GPIO4 → RX BMS; ESP RX GPIO5 ← TX BMS; 9600 8N1**. Уникай підключення контактів живлення UART без перевірки: там може бути повна напруга акумулятора.

**Важливо:** значення проєктного профілю — приклад конкретної збірки, а не універсальні налаштування для всіх LiFePO₄. Завжди перевіряй характеристики своїх елементів і зарядного пристрою.

## Залежності й ліцензія

Використовується зовнішній компонент [`syssi/esphome-jbd-bms`](https://github.com/syssi/esphome-jbd-bms), який поширюється за ліцензією **Apache-2.0**. Його код до цього пакета не входить. Оригінальні файли конфігурації/панелей цього репозиторію ліцензуються за MIT. 

Поточне посилання на зовнішній компонент — `@main`: для відтворюваності варто зафіксувати конкретний перевірений commit після тестування. Працездатність за іншої ревізії BMS не гарантована.

Скріншоти можна додати пізніше — інструкція у [`screenshots/README.md`](screenshots/README.md).


## Стабільні параметри UART

У двох публічних прошивках використано `logger.level: WARN`, `jbd_bms.update_interval: 5s`, `jbd_bms.rx_timeout: 300ms`. Автор повідомляє про відсутність попередніх помилок UART після зміни цих параметрів. Це результат практичного спостереження, а не підтвердження конкретної причини. Спостерігач `uart.debug`, потрібний для обробки EEPROM-відповідей, збережений.
